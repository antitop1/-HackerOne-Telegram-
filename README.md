# -HackerOne-Telegram-
HackerOne Report Generator — Telegram‑бот, который позволяет автоматически генерировать подробные отчёты об уязвимостях на основе короткого описания и примера запроса (request_example), используя OpenAI GPT. Готовые отчёты можно сразу загрузить на сервер через SSH или скачать.

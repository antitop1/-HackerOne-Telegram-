# HackerOne Report Generator in Telegram

📊 **HackerOne Report Generator** — Telegram‑бот, который позволяет автоматически генерировать подробные отчёты об уязвимостях на основе короткого описания и примера запроса (request_example), используя OpenAI GPT. Готовые отчёты можно сразу загрузить на сервер через SSH или скачать.

---

## 🚀 Возможности

- Генерация подробного отчёта об уязвимости на основе краткого описания.
- Парсинг и форматирование рекомендаций, шагов воспроизведения и технических деталей.
- Встраивание скриншотов в HTML‑отчёт.
- Загрузка отчёта на удалённый сервер через SSH/SCP.
- Прокси‑поддержка для запросов к OpenAI.
- Подходит для работы с HackerOne‑типом отчётов.
